# Go Website Analyzer

A lightweight website monitoring and analysis tool built with Go.

This application checks websites for availability and provides useful information such as website status, HTTP status code, and response time.

## Features

- Check website availability
- Detect HTTP status codes
- Measure response time
- Display website UP/DOWN status
- Handle connection errors
- Simple and lightweight Go implementation

## How It Works

The application sends an HTTP request to the target website and analyzes the response. It displays the website status, HTTP status code, response time, and error information when a website cannot be reached.

## Run Locally

This project runs successfully on localhost:8080.

### Requirements

- Go installed on your computer
- Internet connection for checking external websites

### Installation

Clone the repository:

git clone https://github.com/farimazhar/go-website--analyzer.git

Open the project folder:

cd go-website--analyzer

Run the application:

go run .

After starting the application, open your browser and visit:

http://localhost:8080

The Go Website Analyzer will run locally on port 8080 and provide the website analysis results.
